## Первый код который мы сюда положили
В ходе работы мы сюда поместили файлик с готовым кодом. Изначально состав файла был следующим:
```
print("Hello World!")
```
Далее мы сделали первый коммит, в котором изменили содержание файла на это:
```
# Создаем переменные
name = "Студент"
a = 10
b = 5

# Математическая операция
result = a + b

# Вывод результата на экран
print(f"Привет, {name}!")
print(f"Результат сложения {a} + {b} равен {result}")
```
